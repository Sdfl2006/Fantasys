# 🏆 Estudios de Fantasy

Plataforma frontend modular construida con HTML, CSS y JavaScript (Vanilla) para la gestión táctica de ligas Fantasy. 

## 🚀 Características Principales
* **Entorno Multiliga:** Temas visuales inyectados dinámicamente mediante variables CSS dependiendo de la liga seleccionada (FantaPremier, FantaCalcio, FantaLiga).
* **Gestión de Estado Local:** Uso de `localStorage` para persistir el radar de estudio y las selecciones finales de forma segura sin requerir backend.
* **Draft Board Restrictivo:** Algoritmo que bloquea selecciones cuando se alcanzan los límites de plantilla por posición.
* **Herramientas de Estudio:** Ordenamiento dinámico de estadísticas al hacer clic en los encabezados, buscador en tiempo real, movimiento manual de posiciones y purga masiva por categorías.
